TRANSPORT

Manual de usuario

Guía completa de navegación y operación del prototipo, elaborada a partir de pruebas reales con evidencia visual antes y después de enviar los formularios.

Versión documentada: 31/10/2026
Entorno: http://localhost:8080
Ejecución: MANUAL-20261031-025056

Cómo usar este manual

Abra TransPort en http://localhost:8080. Cada capítulo muestra la pantalla, los datos introducidos y el resultado observado. Las capturas con borde rojo corresponden a una función que falló durante la prueba y se conservan como evidencia; consulte el apéndice de incidencias antes de demostrar esos flujos.

Convenciones

  • Evidencia: la pantalla se abrió o el formulario devolvió un resultado normal.
  • Resultado con fallo: el navegador o la aplicación rechazó la operación.
  • Todos los datos creados por la prueba incluyen el prefijo MANUAL-20261031-025056.
